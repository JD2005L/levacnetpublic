Privacy policy: GitHub Repo Navigator

Last updated: 2026-10-01

GitHub Repo Navigator is a Chrome extension that shows every GitHub repository you can access, organized into your own sections, in GitHub's ☰ menu and on the github.com dashboard. This policy explains what it handles and where that data goes.

In short: the extension has no server and sends nothing to its developer or any third party. It talks only to GitHub, with read-only access to repository metadata, and keeps its data in your own browser.

What the extension accesses

DataWhere it comes fromWhy
Your GitHub login nameGitHub's API, after you connectTo show who is connected and to recognise your own account.
GitHub access and refresh tokensGitHub's device-flow sign-in, which you startTo read your repository list.
Repository metadata: ID, owner, name, owner avatar URL, visibility, archived/fork flags, last push timeGitHub's APITo show and organize your repositories.
GitHub App installations: account name and type, whether all or selected repositories are sharedGitHub's APITo tell you which accounts the app can see and what to fix.
Repository descriptions, primary languages and topicsGitHub's API, only when you click "Suggest sections"To build the suggestion preview. Used once, never stored.
Your sections: names, order, collapsed state, and which repository IDs each holdsYouYour organization of the list.

The extension's GitHub access is read-only repository metadata. It cannot read code, issues, pull requests or any other content, and it cannot change anything on GitHub.

It does not read GitHub's web pages for data, does not use GitHub's cookies, and does not collect browsing history, analytics or usage statistics.

Where data is stored

  • This device only (chrome.storage.local, restricted to the extension's own pages and background worker): tokens, your login name, the repository list and its cache metadata. Content scripts running on github.com cannot read this area.

  • Chrome Sync (chrome.storage.sync, only if you use Chrome Sync): your sections, their order and collapsed state, and the repository IDs in each. No tokens, names, descriptions or other repository details are synced. Chrome Sync is operated by Google under Google's privacy policy.

  • Files you choose to export ("Export sections"): your sections plus each listed repository's ID and owner/name, saved where you choose.

Where data is sent

Only to GitHub (github.com for sign-in, api.github.com for the repository list), over HTTPS, as part of the features described above. The extension has no backend server, and no data is sent to the extension's developer or to any other party. Data is never sold or used for advertising, credit or any purpose unrelated to the extension's single purpose.

Your control

  • Disconnect (settings page) deletes the tokens and the cached repository list from that device.

  • Revoke the extension's GitHub App at github.com/settings/apps/authorizations to invalidate its tokens everywhere.

  • Reset sections (settings page) deletes your synced sections on every device.

  • Uninstalling the extension makes Chrome delete its local data.
